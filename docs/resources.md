# Resources

Each step links what you need right then. This page is the full list, for when you want to go deeper or get stuck.

## Learn C# from the start

Pick one and work through it alongside the stages.

- [The C# Player's Guide](https://csharpplayersguide.com/), by RB Whitaker. A book built around small console games and challenges, and the best match for this project. It has a free sample.
- [Brackeys: How to program in C#](https://www.youtube.com/playlist?list=PLPV2KyIb3jR4CtEelGPsmPzlvP7ISPYzR). 8 short videos, from setup to classes. Made for future Unity developers.
- [Bro Code: C# for beginners](https://www.youtube.com/playlist?list=PLZPZq0r_RZOPNy28FDBys3GVP2LiaIyP_). 50 short videos, one per topic. Good for looking up one thing at a time.
- [freeCodeCamp: C# full course](https://www.youtube.com/watch?v=GhQdlIFylQ8). About 4.5 hours, all in one video.
- [Microsoft Learn: Get started with C#](https://learn.microsoft.com/en-us/training/paths/get-started-c-sharp-part-1/). Free, with exercises you run in the browser.
- [C# interactive tutorials](https://learn.microsoft.com/en-us/dotnet/csharp/tour-of-csharp/tutorials/). Short official tutorials on numbers, branches, loops, and more.

## Warm-up project

## Game architecture

[Game Programming Patterns](https://gameprogrammingpatterns.com/), by Robert Nystrom, is free online. Most relevant chapters:

- [Game Loop](https://gameprogrammingpatterns.com/game-loop.html): Step 3.1
- [State](https://gameprogrammingpatterns.com/state.html): Step 3.2
- [Command](https://gameprogrammingpatterns.com/command.html): turning typed commands into actions
- [Update Method](https://gameprogrammingpatterns.com/update-method.html) and [Component](https://gameprogrammingpatterns.com/component.html): how Unity organizes games

Also:

- [State pattern (refactoring.guru)](https://refactoring.guru/design-patterns/state) · [C# example](https://refactoring.guru/design-patterns/state/csharp/example)
- [Separation of concerns](https://en.wikipedia.org/wiki/Separation_of_concerns)
- Text adventures: [Building a text adventure in C# (video)](https://www.youtube.com/watch?v=qKsE-DtKRlg) · [Classic adventure-game parser design (Stanford; C++ code, but the design carries over)](https://nifty.stanford.edu/2002/EstellNifty2002/fulladventure/index.html)

Build your own version first, then compare.
